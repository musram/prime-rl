# Replication Task: Calculate Sum Function

## Objective

Implement the `calculate_sum()` function in `src/module.py` to pass all tests.

## Function Signature

```python
def calculate_sum(numbers: list) -> int:
    """
    Calculate the sum of a list of numbers.
    
    Args:
        numbers: List of integers
        
    Returns:
        Sum of all numbers in the list
    """
```

## Success Criteria

All tests in `tests/test_module.py` must pass.

## Running Tests

```bash
cd benchmarks/replication/project_a
pytest -q
```

## Expected Implementation

The function should return the sum of all numbers in the input list.
For an empty list, it should return 0.
